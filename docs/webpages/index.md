ESL-Studio
==========

Version: {version} build date: {build_date}

These webpages have the documentation for the latest release of 
ESL-Studio.

We recommend beginning with the [introduction to ESL-Studio](introduction.md) 
and for more details on using ESL-Studio go to the 
[overview in the user guide](guides/overview.md) webpages.

The main website for [ESL Software](https://www.isimsimulation.com/)
covers the ESL Software simulation product 
[features](https://www.isimsimulation.com/products/features.html)
and has the full set of 
[documents](https://www.isimsimulation.com/documents/) for it.

The [ESL-Studio Help Pages](https://www.isimsimulation.com/help_pages/esl-studio/) 
cover the release (1.2.0.30) as provided with the ESL Software simulation product
(ESL-Pro or ESL-Lite version 8.3.0.1).

The [ESL-Studio repository](https://github.com/ryllank/esl-studio) has 
the git repository on GitHub.
  
You may download the latest packaged release for ESL-Studio from the 
Assets in the 
[Releases](https://github.com/ryllank/esl-studio/releases) section on 
the GitHub repository.
